- Mean: alexandria 2109.6, native 2469.9.
- Alexandria range 200–6875; the four 200-token floors are tasks where nothing was retrieved

## 6. Interpretation (kept separate from the numbers above)

- **H1 (token cost): not supported on this subset.** On a small, semantically-clustered library the
  token advantage collapses to parity (~1.03×). Alexandria only wins big on tokens when the library
  is large and diverse enough that native's resident-description preload dominates. At N=20 there is
  little to preload, so native is already cheap.
- **H2 (latency): supported (direction), immaterial (magnitude).** Alexandria's network FTS lookup is
  ~50× slower than native's local lookup in relative terms, but ~48 ms is noise next to the LLM turn.
- **H3 (accuracy): mixed, leaning native.** Native edged accuracy (0.85 vs 0.70), but the two systems
  fail differently: native's one real retrieval error was a close-semantics near-neighbor confusion;
  Alexandria's errors were mostly the model declining to consult, plus one FTS empty-result. The
  close-semantics flavor stresses *both* systems but in different places.

## 7. Threats to validity

- **nrep=1, warmup=0.** No per-cell dispersion; single observation per task. CIs are across tasks,
  not across repeats. Compliance failures (model skipping the tool) are LLM-nondeterministic and
  would average out with nrep≥3 — treat the 70% vs 85% gap as indicative, not settled.
- **Consult-compliance confound.** Both conditions had no-consult failures (alex 4, native 2). These
  are prompt-adherence failures, not retrieval failures, but they count against model-choice accuracy.
  A cleaner retrieval-only accuracy (conditioned on consulted=True) would be alex 14/16 vs native 17/18.
- **Native accuracy/token are modeled** (documented preload + progressive disclosure), not scraped;
  if real disclosure is leaner, native tokens would be lower — conservative for H1.
- **Tokenizer proxy** `cl100k_base` ≈ but ≠ Claude's tokenizer.
- **Scope.** Single machine, haiku/low, Claude Code only, this one subset (close-semantics, N=20).
  No cross-flavor or cross-size claims until random-20 / sparse-20 / the -100s are run.
